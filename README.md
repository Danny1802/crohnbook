# Crohnbook

Gebouwde versie van een persoonlijk IBD-dagboek: een offline webapp die
ontlasting, symptomen, voeding en medicatie bijhoudt en daar rapportages van
maakt voor de MDL-arts en de dietist.

Alle gegevens blijven in de browserdatabase van je eigen toestel. Er is geen
server, geen account en geen enkele vorm van dataverzameling. Deze repository
bevat alleen de gebouwde bestanden die nodig zijn om de app te serveren.

Crohnbook registreert en rekent. Het stelt geen diagnoses en geeft geen
behandeladvies.
